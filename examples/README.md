# 离线示例

在仓库根目录运行：

```bash
python examples/run_offline_demo.py
```

脚本只用虚构的“示例校园号”和“资料整理工作坊”生成一条候选资讯，输出到 `.demo-output/`。它不检查真实收藏、不访问微信、不调用模型、不打开秀米；已写好的假想阅读记录只用于展示数据交接和排版。

可以打开 `.demo-output/layout/校园资讯_普通版.html` 或秀米兼容版查看效果。所有日期、事项和微信链接均为结构示例，不可据此参加活动或直接发布。

正式采集仍需用户自己指定信源、文章日期与有效日期。可用 `--output` 指定其他演示目录。

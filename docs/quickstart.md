# 首次使用

## 先理解安装的对象

仓库包括给人阅读的 README、文档、示例和 CI。实际 Skill 是 `skills/campus-news-collect/` 文件夹，入口为 SKILL.md。将它安装到宿主规定的技能目录，按宿主界面选择或提及它。

不必把 README 一并当作 Agent 指令加载。脚本、references、assets 需随 Skill 保留；只复制 SKILL.md 会缺少实现和模板。

## 连接下载工具

1. 从 [wechat-mp-tools 项目](https://github.com/x554960766/wechat-mp-tools) 按其说明安装软件。
2. 用户本人完成需要的登录，把目标公众号加入收藏。
3. 启动下载工具的服务，默认地址为 `http://127.0.0.1:5200`。适配器使用 v2.3.1 的接口约定，更换版本时检查接口是否一致。
4. 确认工具能实际保存 MD、PDF、HTML 和图片。Skill 不改软件设置，某格式缺失会如实报告。

不需要把 Cookie、登录二维码或账号池文件发给 Agent。适配器调用已有本地服务。云端 Agent 不能直接通过自己的 localhost 访问你的电脑。

## 准备输入

范围 TXT 使用 UTF-8，每行 `公众号完整名称，（开）` 或 `公众号完整名称，（关）`。Agent 会只读核对开启账号的收藏，不自行添加、取消或模糊替换。

文章采集日期必填，包含首尾日。资讯有效日期须指定另一个区间，也可明确选择“不限”；两种日期不能混为一谈。

例如“文章发布于7日至13日，事项在14日至20日仍有用”表示两个独立条件。有效日期不限则保留新闻事件实际时间，仍然不能把已截止的报名写成开放。

## 与 Agent 对话

```text
使用校园资讯采编。
公众号范围TXT：我的文件路径
文章采集日期：我指定的开始日期 至 结束日期
资讯有效日期：不限
先给我候选清单、逐篇筛选理由、推文文案和HTML排版。
```

缺少输入时 Agent 会询问；未收藏则列出名称，请你先收藏，再重新核对。日期、范围、已读资料、待确认项均会记录在本次输出中。

## 运行到哪里由任务决定

- 只采集：原文资料、阅读索引与覆盖记录。
- 筛选：候选清单、每篇去留理由、拆分/合并后的资讯和证据。
- 排版：文案MD、两版HTML、标题概要及编辑核对清单。未确认选题时是候选稿。
- 导入秀米：用户明确要求后调用单独准备的 all-to-xiumi，用户本人扫码，分步导入和保存重开核验。

最终选题、事实复核、配图和发布由编辑掌握。默认模板省略栏目头图和“票务及学分”，END后无正文；其他栏目样式可由用户另行指定。

## 出问题时看哪里

| 情况 | 检查 |
| --- | --- |
| 工具无法连接 | 软件是否启动、地址端口是否正确；连接失败不等于未收藏 |
| 文章数偏少 | 收藏范围、分页终止原因、授权状态及渠道收录限制；空列表不能证明没发文 |
| 日期未知或冲突 | 独立资料目录和日期依据，不用下载时间填补 |
| MD只有图片 | 按索引补读必要图片或PDF，不能称已读完 |
| PDF缺失 | 保留已生成格式并报告，不改扩展名冒充 |
| 秀米保存失败 | 保留编辑页，核对登录/容量，不删除已有稿件 |

脚本参数与 API 详见 Skill 的 [工具接入说明](../skills/campus-news-collect/references/tools.md)。
